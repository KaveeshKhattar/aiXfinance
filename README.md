# Binder — AI Sales Coach

Glanceable coaching for insurance cold calls. One line the broker can say out loud. Then silence.

This repo implements the four-stage Binder roadmap:

| Stage | Product | Proof in the app |
| --- | --- | --- |
| 1 | Post-call coach | `/debriefs` + auto debrief after every replay |
| 2 | Real-time whisper | `/` live replay or microphone |
| 3 | Account memory | `/accounts` — prior objections change the whisper |
| 4 | Team intelligence | `/intelligence` — openers, objections, brokers |

## Demo (judges)

1. `npm install && npm run dev`
2. Open [http://localhost:3000](http://localhost:3000)
3. Replay **Acme · gatekeeper → Sarah**
4. Watch Binder stay **silent** on filler, then whisper a **single line** on “happy with our current broker”
5. That line uses **account memory** (May objection), not a generic savings pitch
6. After the call, read the debrief + CRM payload
7. Open Intelligence for team-level opener A/B and objection conversion

**Data note:** Seeded transcripts are **synthetic insurance roleplays**, not real recordings. Live mic calls are stored separately and labeled when synthetic is false.

## What it does

- Classifies **gatekeeper vs decision maker** and call stage: Intro → Gatekeeper → Discovery → Objection → Close
- Detects reflex vs genuine objections (`send an email`, `we're all set`, `happy with our broker`, …)
- **Intervention detector**: most turns produce **silence**
- Fast path is a local playbook (no network). Optional LLM only polishes debriefs
- Never invents coverage, prices, carriers, or the prospect’s policy. Unknown facts become questions.

## Optional LLM

Works with no key. If you set one, debriefs can be generated by any OpenAI-compatible API (OpenAI, Groq, NVIDIA NIM, etc.):

```bash
LLM_API_KEY=...
LLM_BASE_URL=https://api.openai.com/v1
LLM_MODEL=gpt-4o-mini
```

Copy `.env.example` to `.env.local`.

## Optional PRISM tracing

Binder can send live coach and post-call debrief traces to PRISM by BlockConvey. Create a PRISM project, generate an ingest key, then set:

```bash
PRISMTRACE_HOST=https://prism.blockconvey.com
PRISMTRACE_PROJECT_ID=...
PRISMTRACE_API_KEY=pt-sk-...
```

When configured, `/api/coach` emits one trace per live coaching decision and `/api/analyze` emits the post-call debrief trace with the same `session_id`.
